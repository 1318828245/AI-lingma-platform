# 生产部署手册

目标环境：OpenCloudOS + Docker Compose + 宿主 Nginx。应用目录为 `/opt/ai-lingma`，运行数据为 `/srv/ai-lingma-data`。日常命令见 [部署命令](部署命令.md)。

## 1. 初始化

使用具备 sudo 权限的 `deploy` 用户：

```bash
sudo docker version
sudo docker compose version

sudo mkdir -p /opt/ai-lingma /srv/ai-lingma-data
sudo chown -R deploy:deploy /opt/ai-lingma /srv/ai-lingma-data
git clone <仓库地址> /opt/ai-lingma
cd /opt/ai-lingma
cp .env.production.example .env.production
chmod 600 .env.production
```

## 2. 配置生产环境

编辑 `/opt/ai-lingma/.env.production`。至少设置数据库密码、JWT 密钥、管理员密码、模型密钥和以下站点配置：

```dotenv
AI_LINGMA_CORS_ORIGINS=["https://ai-lingma-platform.malanse.site"]
AI_LINGMA_PUBLIC_BASE_URL=https://ai-lingma-platform.malanse.site
AI_LINGMA_BUILD_MODE=real
AI_LINGMA_COMMAND_MODE=sandbox
AI_LINGMA_DATA_DIR=/srv/ai-lingma-data
AI_LINGMA_RUNTIME_UID=1002
AI_LINGMA_RUNTIME_GID=1002
```

`AI_LINGMA_PUBLIC_BASE_URL` 必须是用户浏览器实际访问的 HTTPS 地址，不能填写 `backend`、容器 IP 或 `127.0.0.1`。`real` 是 Vue 预览和发布的必要条件；`mock` 仅用于离线结构测试。

`.env.production` 不提交 Git，也不应出现在聊天、截图或日志中。

## 3. 启动应用

```bash
cd /opt/ai-lingma
sudo docker compose --env-file .env.production up -d --build
sudo docker compose --env-file .env.production ps
curl -I http://127.0.0.1:8080/healthz
```

Compose 启动 PostgreSQL、backend 与 web。只有 web 绑定宿主机 `127.0.0.1:8080`；不要直接向公网暴露 backend 或 PostgreSQL。

## 4. 手动配置宿主 Nginx

先将域名 `ai-lingma-platform.malanse.site` 的 A 记录指向服务器公网 IP，并在云安全组与服务器防火墙放行 TCP 80、443。

证书签发前可先使用 HTTP 反代；签发后使用以下完整配置。证书路径必须替换为服务器实际路径：

```nginx
server {
    listen 80;
    server_name ai-lingma-platform.malanse.site;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name ai-lingma-platform.malanse.site;

    ssl_certificate     /实际路径/fullchain.pem;
    ssl_certificate_key /实际路径/privkey.pem;
    client_max_body_size 2m;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_buffering off;
        proxy_request_buffering off;
        proxy_read_timeout 1200s;
        proxy_send_timeout 1200s;
    }
}
```

本机现有站点文件为 `/www/server/panel/vhost/nginx/ai-lingma.conf` 时，可先备份再编辑：

```bash
sudo cp /www/server/panel/vhost/nginx/ai-lingma.conf \
  /www/server/panel/vhost/nginx/ai-lingma.conf.bak
sudo nano /www/server/panel/vhost/nginx/ai-lingma.conf
sudo /www/server/nginx/sbin/nginx -t -c /www/server/nginx/conf/nginx.conf
sudo /www/server/nginx/sbin/nginx -s reload -c /www/server/nginx/conf/nginx.conf
```

外层 Nginx 必须传递 `X-Forwarded-Proto`；内层 web Nginx 会据此保持 HTTPS 公开链接。

## 5. 验收

```bash
curl -I http://ai-lingma-platform.malanse.site
curl -I https://ai-lingma-platform.malanse.site
curl -I https://ai-lingma-platform.malanse.site/api/health
```

HTTP 应重定向到 HTTPS；HTTPS 首页和健康检查应返回 `200`。随后在浏览器依次验证登录、HTML 生成、Vue 生成、预览、修改与发布。

## Vue 预览白屏

Vue 预览地址位于 `/preview/<项目ID>/`。构建后的 `dist/index.html` 必须引用相对资源路径 `./assets/...`；若出现 `/assets/...`，浏览器会在站点根路径请求 JS/CSS，导致模块 MIME 错误和白屏。

检查当前产物：

```bash
sudo sed -n '1,30p' \
  /srv/ai-lingma-data/workspaces/vue/<项目标识>/dist/index.html
```

临时重建单个项目：

```bash
sudo docker compose --env-file .env.production exec -T backend sh -lc \
'cd /data/workspaces/vue/<项目标识> && npm run build -- --base=./'
```

永久修复为：确认 `AI_LINGMA_BUILD_MODE=real`，更新并重建 backend 镜像，然后通过项目重建接口重新构建旧项目。正确请求应是 `/preview/<项目ID>/assets/...`，返回 `200`。

## 备份、恢复与升级

备份：

```bash
sudo /opt/ai-lingma/scripts/backup.sh
```

升级前先备份，然后：

```bash
cd /opt/ai-lingma
git status -sb
git pull --ff-only origin main
sudo docker compose --env-file .env.production up -d --build
```

不要删除 PostgreSQL 卷或 `/srv/ai-lingma-data`。升级后重复健康检查与 Vue 预览验收。
