# 生产常用命令

以下命令在服务器 `/opt/ai-lingma` 执行，均使用 `.env.production`。

## 状态与日志

```bash
sudo docker compose --env-file .env.production ps
sudo docker compose --env-file .env.production logs --tail=200 backend
sudo docker compose --env-file .env.production logs -f backend
sudo docker compose --env-file .env.production logs --tail=200 web
```

## 更新策略

修改 `.env.production` 后，仅重建 backend 容器：

```bash
sudo docker compose --env-file .env.production up -d --force-recreate --no-deps backend
```

修改 backend Python 代码或后端 Dockerfile 后：

```bash
sudo docker compose --env-file .env.production up -d --build --no-deps backend
```

修改前端代码、`docker/nginx/default.conf` 或前端 Dockerfile 后：

```bash
sudo docker compose --env-file .env.production up -d --build --no-deps web
```

更新多个服务或不确定变更范围时：

```bash
git status -sb
git pull --ff-only origin main
sudo docker compose --env-file .env.production up -d --build backend web
```

## Vue 项目重建

检查构建模式：

```bash
sudo docker compose --env-file .env.production exec -T backend \
  python -c "from app.core.config import get_settings; print(get_settings().build_mode)"
```

重建单个工作区（仅用于排障）：

```bash
sudo docker compose --env-file .env.production exec -T backend sh -lc \
'cd /data/workspaces/vue/<项目标识> && npm run build -- --base=./'
```

检查产物资源路径：

```bash
sudo docker compose --env-file .env.production exec -T backend sh -lc \
'grep -nE "(src|href)=.*assets" /data/workspaces/vue/<项目标识>/dist/index.html'
```

预期为 `./assets/...`；`/assets/...` 会使预览白屏。

## 备份与 Nginx

```bash
sudo /opt/ai-lingma/scripts/backup.sh
sudo /www/server/nginx/sbin/nginx -t -c /www/server/nginx/conf/nginx.conf
sudo /www/server/nginx/sbin/nginx -s reload -c /www/server/nginx/conf/nginx.conf
```

## 无密钥诊断

```bash
sudo docker compose --env-file .env.production exec -T backend \
  python -c 'from app.core.config import get_settings; s=get_settings(); print({"build_mode":s.build_mode,"llm_model":s.llm_model,"llm_key_set":bool(s.llm_api_key),"vision_key_set":bool(s.eval_vision_api_key)})'
```
