# 生产部署核心命令

以下命令在服务器 `/opt/ai-lingma` 执行。

## 启动、停止、重启

```bash
sudo docker compose --env-file .env.production up -d
sudo docker compose --env-file .env.production stop
sudo docker compose --env-file .env.production restart
```

## 状态和日志

```bash
sudo docker compose --env-file .env.production ps
sudo docker compose --env-file .env.production logs --tail=200 backend
sudo docker compose --env-file .env.production logs -f backend
```

## 配置或代码更新

修改 `.env.production` 后：

```bash
sudo docker compose --env-file .env.production up -d --force-recreate backend
```

修改代码或 Dockerfile 后：

```bash
sudo docker compose --env-file .env.production up -d --build backend web
```

## 拉取最新代码

```bash
git status -sb
git pull --ff-only origin main
sudo docker compose --env-file .env.production up -d --build
```

## 备份

```bash
sudo /opt/ai-lingma/scripts/backup.sh
```

## 检查模型配置（不显示密钥）

```bash
sudo docker compose --env-file .env.production exec -T backend \
  python -c 'from app.core.config import get_settings; s=get_settings(); print({"llm_model":s.llm_model,"vision_provider":s.eval_vision_provider,"vision_model":s.eval_vision_model,"llm_key_set":bool(s.llm_api_key),"vision_key_set":bool(s.eval_vision_api_key)})'
```

## 检查 Chromium

```bash
sudo docker compose --env-file .env.production exec -T backend chromium --version
```

## Nginx 检查和重载

```bash
sudo /www/server/nginx/sbin/nginx -t -c /www/server/nginx/conf/nginx.conf
sudo /www/server/nginx/sbin/nginx -s reload -c /www/server/nginx/conf/nginx.conf
```
